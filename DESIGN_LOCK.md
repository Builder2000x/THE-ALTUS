# Altus visual system — locked

The following are approved, stable parts of the Altus website and must not be
replaced while implementing content, publishing, newsletter, video, or store
features:

- Warm Ivory page background and warm editorial palette
- Kinetic homepage hero with the mountain / goat banner and motion system
- Editorial display typography, navigation, spacing and page hierarchy
- Reveal, scroll, hover and micro-interaction treatments
- Page headers for News, Videos, Store, About and Subscribe

Content work must use these existing components and layouts. It may add real
Altus content or empty states, but must never inject fabricated editorial
stories or silently replace the approved visual system.
